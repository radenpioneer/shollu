### Tech Stack

**Frontend:**
- React 19.1.0
- TypeScript 5.8.3 (strict mode)
- Luxon 3.7.2 (dates)
- Nanostores 1.1.0 (state)
- Tailwind CSS 4.1.17 (styling)

**Backend:**
- Tauri 2.x (Rust)
- SQLite (database)

### Important Rules

1. **Always use TypeScript strict mode** - No implicit any
2. **Use Nanostores for state** - Not Context or Redux
3. **Use Tailwind CSS only** - No custom CSS
4. **Follow path aliases** - `@/components`, `@/lib`, etc.
5. **Sign log files** - Add Ona signature to generated docs
6. **Test your changes** - Run `npm run lint` and `npm run build`
7. **Follow commit conventions** - `feat:`, `fix:`, `docs:`, etc.

### When Adding Features

1. Check if it's in the current phase (see `logs/PROJECT_PLAN.md`)
2. Follow established patterns (see existing code)
3. Add types to `src/types/`
4. Add stores to `src/stores/` if needed
5. Create components in `src/components/`
6. Write tests (when test framework is set up)
7. Update documentation in `logs/`

### When Fixing Bugs

1. Understand the issue
2. Check if it affects other parts
3. Write a test to reproduce (if possible)
4. Fix the issue
5. Verify the fix
6. Update documentation if needed

### Code Style Example

```typescript
// Good ✅
import { useStore } from '@nanostores/react';
import { $prayerTimes } from '@/stores/prayer-times';
import { cn } from '@/lib/utils';

interface Props {
  className?: string;
}

export default function PrayerCard({ className }: Props) {
  const times = useStore($prayerTimes);
  
  return (
    <div className={cn('rounded-lg p-4', className)}>
      <h3 className="text-lg font-semibold">{times.fajr}</h3>
    </div>
  );
}

// Bad ❌
import React from 'react'; // Not needed in React 19
import './PrayerCard.css'; // Don't use custom CSS

function PrayerCard(props: any) { // Use proper types
  const [times, setTimes] = React.useState(); // Use Nanostores
  
  return (
    <div style={{ padding: '16px' }}> {/* Use Tailwind */}
      <h3>{props.time}</h3>
    </div>
  );
}
```

### Common Patterns

**Nanostores:**
```typescript
// Define store
export const $settings = map<Settings>(defaultSettings);

// Use in component
const settings = useStore($settings);

// Update store
$settings.set({ ...settings, theme: 'dark' });
```

**Tailwind CSS:**
```typescript
// Conditional classes
<div className={cn(
  'base-classes',
  isActive && 'active-classes',
  className
)} />
```

**Error Handling:**
```typescript
try {
  const result = await someAsyncOperation();
  return result;
} catch (error) {
  console.error('Operation failed:', error);
  // Show user-friendly message
  showNotification('Something went wrong. Please try again.');
}
```
