**Key Decisions:**

1. **Database: SQLite** (not libSQL or PGlite)
   - Already integrated via tauri-plugin-sql
   - Perfect for offline-first desktop app
   - Smallest footprint (~600KB)
   - Most mature and stable (24 years)
   - No custom integration needed

2. **API Strategy: Multi-Provider**
   - Kemenag (Indonesia) - Official government data via community scraper
   - Aladhan (Global) - Official REST API
   - Local Calculation - Always works fallback
   - Smart selection based on user location/locale

3. **Cache Strategy: Cache-First**
   - Always read cache first (instant, 0ms)
   - Background refresh (startup, daily, location change)
   - 30-day bulk caching (reduces API calls by 97%)
   - Never blocks UI on network calls
